# Gabor Frames for an Even Rational Window with Symmetric Poles
This repository contains MATLAB code accompanying the paper
**R. Ghosh, "Frame Regions and Non-Frame Obstructions for an Even Rational Window."**
The paper studies the Gabor frame set generated by
$g(x)=\frac{x^2-1}{(x^2+1)(x^2+4)(x^2+9)}.$
The files in this repository provide symbolic and numerical verification of several algebraic calculations used in the proofs.

## Files

- `Lemma_Wronskian.mlx`  
  Symbolic verification of the Wronskian calculations used in Lemma 2.2, including the positivity of the shifted polynomial coefficients.

- `Lemma_F_beta_ii.mlx`  
  Exact symbolic computations used in the proof of Lemma 2.4(ii).

- `Lemma_F_beta_iii.mlx`  
  Exact symbolic computations used in the proof of Lemma 2.4(iii).

- `Simplification.mlx`  
  Symbolic factorization and simplification used in Proposition 3.1, equation no (3.24), Theorem 1.4, equation no (4.2), Theorem 1.4, equation no (4.4).

- `Conjecture_g2.mlx`  
  Numerical computations associated with the determinant condition for the family $\alpha\beta=\frac{p}{p+1}$, including the numerical evidence discussed in Section 4.


The computations were carried out in MATLAB using the Symbolic Math Toolbox. The `.mlx` files are MATLAB Live Scripts and can be opened and executed directly in MATLAB.
Numerical computations in `Conjecture_g2.mlx` are intended as numerical evidence and are not used as substitutes for the analytic proofs in the paper.
